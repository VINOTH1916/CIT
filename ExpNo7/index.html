What this experiment demonstrates

Divide-and-conquer matrix multiplication, measured against the classical method

Naive multiplication calculates every output cell with a full row-by-column dot product, requiring n³ scalar multiplications. Strassen divides each matrix into four quadrants and uses 7 recursive products instead of 8. That lowers the asymptotic running time, although the extra additions and temporary matrices can make it slower for small matrices.

Naive: Θ(n³)   |   Strassen: T(n) = 7T(n/2) + 18(n/2)² = Θ(nlog₂7) ≈ Θ(n2.807)
1. PadPad an arbitrary n × n input with zeros to the next power of two.
2. SplitPartition A and B into A₁₁…A₂₂ and B₁₁…B₂₂ quadrants.
3. RecurseCalculate M₁…M₇; use naive multiplication at the cut-off.
4. CombineRebuild C₁₁…C₂₂, then trim away the padding.

Core program code

The browser benchmark uses the same hybrid Strassen approach shown below

Use a cut-off (such as 64) so that small submatrices use the faster classical routine. The complete interactive implementation is the script on this page.

function strassen(A, B, cutoff) {
  const n = A.length;
  if (n <= cutoff) return naive(A, B);
  const [A11, A12, A21, A22] = split(A);
  const [B11, B12, B21, B22] = split(B);
  const M1 = strassen(add(A11,A22), add(B11,B22), cutoff);
  const M2 = strassen(add(A21,A22), B11, cutoff);
  const M3 = strassen(A11, sub(B12,B22), cutoff);
  const M4 = strassen(A22, sub(B21,B11), cutoff);
  const M5 = strassen(add(A11,A12), B22, cutoff);
  const M6 = strassen(sub(A21,A11), add(B11,B12), cutoff);
  const M7 = strassen(sub(A12,A22), add(B21,B22), cutoff);
  const C11 = add(sub(add(M1,M4),M5),M7);
  const C12 = add(M3,M5), C21 = add(M2,M4);
  const C22 = add(sub(add(M1,M3),M2),M6);
  return join(C11, C12, C21, C22);
}

// Pad each input to the next power of two, call strassen,
// then return only the original n × n top-left result.
